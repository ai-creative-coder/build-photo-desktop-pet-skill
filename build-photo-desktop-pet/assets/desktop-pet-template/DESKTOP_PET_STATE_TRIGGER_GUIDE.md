# __PRODUCT_NAME__ 状态触发与隐私说明

版本：`__VERSION__`

| 状态 | 触发条件 | 退出规则 |
|---|---|---|
| 休息中 | 没有其他有效状态 | 任一更高状态到达即退出 |
| 点击打招呼 | 单击桌宠且位移低于7px | 播放一轮后恢复基础状态 |
| 拖动加油 | 按住桌宠并真实移动至少7px，立即显示加油鼓励动作 | 松手后自然完成当前一轮再恢复 |
| 伸展活动 | 15分钟未点击或拖动桌宠 | 播放一轮并重新计时 |
| 思考中 | 文档/沟通/设计中真实敲键，或编码停顿超过30秒 | 工作会话结束后退出 |
| 编码中 | 受支持编程工具前台且真实敲键 | 停顿超过30秒转思考 |
| 处理中 | 受跟踪构建、导出、压缩或批任务仍运行 | 成功转完成，失败转错误 |
| 调试中 | 受支持调试器运行且存在编码上下文 | 调试器退出后恢复工作状态 |
| 发生错误 | 跟踪任务非0退出或失败事件 | 播放一轮 |
| 喝水提醒 | 活跃使用60分钟且未离席5分钟 | 播放一轮并重新累计 |
| 任务完成 | 任务成功或≥15秒工作会话结束 | 播放一轮 |
| 新消息提醒 | 授权通知或白名单通讯软件出现新消息信号 | 最高即时优先级，播放后恢复最新状态 |
| 休息提醒 | 活跃使用50分钟且未离席5分钟 | 播放一轮并重新累计 |

## 优先级

```text
新消息 > 拖动 > 点击 > 错误 > 完成 > 健康提醒 > 伸展 > 调试 > 编码 > 处理 > 思考 > 休息
```

新消息播放期间，基础工作状态继续更新；播放结束后恢复最新仍有效的状态，不固定返回待机。

## 隐私边界

- 读取：前台应用类别、最近是否发生输入、系统空闲时间、受跟踪任务状态、允许来源的通知元数据。
- 不读取：具体按键、代码、文档正文、聊天正文、发送人、附件、剪贴板和屏幕画面。
- 消息通知路径需要用户授权；拒绝后其他状态仍可使用。

## 平台差异

- Windows版使用Windows前台窗口、进程、输入活动、通知和注册表启动项接口。
- macOS版必须以安装包实际通过的原生触发项为准。需要系统级输入观察时，应请求“辅助功能”授权并允许用户拒绝。
- macOS版不得读取其他应用内容或抓取通知中心数据库；没有公开且经授权的集成时，不承诺覆盖所有第三方IM新消息。
- 任一平台未实现或未通过验收的触发条件，必须从该平台说明中删除，不能只因共享界面可运行就宣称功能一致。
